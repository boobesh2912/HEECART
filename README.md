A modern, high-converting e-commerce web platform engineered for **HEECART** (Bespoke Keepsakes & Corporate Gifting), inspired by leading luxury gifting platforms like [Giftana](https://giftana.com/).

Designed in an aesthetic **Luxury Red & Black** theme with Google's **Inter** typography, fluid responsiveness across all screens (Mobile, Tablet, Desktop), and copywriting crafted to build immediate credibility and emotional resonance.

---

## 🌟 Key Features

### 1. Dual Gifting Catalog
- **Individual Personalized Gifts**: Handcrafted photo mosaic frames (up to 50 photos blended), illuminated Spotify acrylic plaques with warm beechwood LED bases, 3D laser-engraved optical crystal keepsakes, personalized couple mugs, RFID leather wallets & custom keychains.
- **Corporate Bulk Hampers (Giftana-style)**: The Royale Executive Welcome Hamper (Smart LED temperature flask, PU leather notebook, metal stylus pen, metal USB drive), Eco-friendly Bamboo sets, Artisan Gourmet dry fruit decanters, and Tech executive kits.

### 2. Interactive Real-Time Customizer Modal
- **Live Laser Engraving Visualizer**: Type any recipient name, corporate emblem, or date, and view the typography render dynamically on the product mockup.
- **Font Selector**: Choose between *Signature Serif*, *Modern Sans*, *Luxury Script*, and *Tech Monospace*.
- **Photo Upload Simulator**: Upload photos with instant visual feedback and crop preview.
- **Signature Keepsake Packaging**: Option to include Heecart's red & black keepsake gift box with satin ribbon and gold-foil wax seal.
- **Direct WhatsApp Order Generator**: Pre-fills product details, custom engravings, and total price for 1-click WhatsApp checkout.

### 3. Corporate RFQ & Volume Slab Calculator
- Interactive quantity slider (10 to 1,000+ units) with live slab discount calculation (up to 45% off).
- Input Tax Credit (18% GST invoice breakdown) for corporate procurement teams.
- Direct Request for Quote (RFQ) submission with instant digital mockup assurance.

### 4. Live Order & Mockup Tracking Simulator
- Look up any order ID (e.g., `HEEC-8924`) to follow the real-time fulfillment roadmap:
  `Order Placed` ➔ `Digital Mockup Approved on WhatsApp` ➔ `Fiber Laser Engraving & Handcrafting` ➔ `Quality Inspection` ➔ `BlueDart Express Air Dispatch` ➔ `Doorstep Delivery`.

### 5. High-Converting E-Commerce Bag & Checkout
- Slide-over cart drawer with live free shipping progress bar (orders above ₹999).
- Promo code engine (supports `HEECART10` for 10% off and `BULKFREE` for free express shipping).
- 256-bit SSL encrypted checkout with UPI, Cards, NetBanking, and COD options.
- Celebration confetti on order completion and direct WhatsApp receipt link.

### 6. Social Proof & Community Integration
- Verified corporate HR & individual customer reviews.
- Instagram gallery connected directly to [@heecart_com](https://www.instagram.com/heecart_com/).
- Transparent FAQ accordion addressing mockup approvals, packaging security, and transit replacement warranties.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Local Development
```bash
# Clone the repository
git clone https://github.com/boobesh2912/HEECART.git
cd HEECART

# Install dependencies
npm install

# Start development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
